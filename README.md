# Halqmak

Telegram-бот для управления подписками GO в Remnawave. В личном чате команда `/start` открывает меню. Можно создать одну запись, 20 записей или указать своё количество. После выбора количества бот запрашивает подтверждение. Список показывает ник, ID, статус и кнопку копирования ссылки в каждой строке. Экран создания показывает число созданных записей и таблицу с никами, ID и ссылками. CSV доступен в обоих списках.

При создании бот генерирует ник с началом `go_`. Если панель поддерживает переименование, бот устанавливает ник `go_<id>`. В таблице всегда показан ник, который вернула панель.

Записи получают статус ACTIVE, тег GO, внутренний сквад GO и безлимитный трафик. Панель требует дату окончания, по умолчанию используется 1 января 2099 года UTC. В списке активных подписок показываются записи с тегом GO, статусом ACTIVE и непросроченной датой окончания.

Нажмите на ник прямо в таблице, чтобы открыть карточку с ID, датами создания и подключений, трафиком и сквадами. Зарегистрированные устройства HWID показаны в отдельной таблице с моделью, платформой и версией ОС. Для деактивации или удаления сначала нажмите «Продолжить», затем подтвердите действие кнопкой «Да, деактивировать» или «Да, удалить». Отмена на любом шаге возвращает к карточке. Деактивированные записи доступны в «Все подписки GO».

Токен панели должен разрешать соответствующие действия над пользователями. Для показа устройств нужен доступ к `GET /api/hwid/devices/{userId}` (`hwid-user-devices:list-by-user`). Если панель запрещает запрос, в карточке отображается «Данные недоступны». Регистрация устройств зависит от настроек HWID панели и поддержки HWID клиентским приложением.

## Деплой через Docker Compose

На сервере с Docker Engine и Docker Compose v2 выполните:

```sh
git clone https://github.com/Null-ch/halqmak.git
cd halqmak
install -m 600 .env.example .env
nano .env
```

Заполните `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ADMIN_IDS` (числовые ID через запятую), `REM_BASE_URL` (HTTPS-адрес панели с окончанием `/api`) и `REM_API_TOKEN`. В панели должен существовать внутренний сквад GO. Бот использует long polling, поэтому входящие порты не нужны. У токена должен быть отключён webhook. Если бот уже работает через systemd или на другом сервере, остановите тот экземпляр до запуска контейнера.

```sh
docker compose up -d --build
docker compose ps
docker compose logs --tail=100 bot
```

После запуска отправьте боту `/start` из разрешённого личного чата.

Для обновления выполните `git pull --ff-only` и `docker compose up -d --build` из каталога репозитория. Чтобы остановить контейнер, выполните `docker compose down`.

## Запуск через Python

Нужен Python 3.10 или новее. Создайте `.env` по образцу `.env.example`, заполните токены, URL панели с окончанием `/api` и числовые Telegram ID администраторов через запятую. В панели должен существовать внутренний сквад GO. Допускаются только личные чаты указанных администраторов. При использовании long polling у токена не должно быть активного webhook или другого запущенного экземпляра бота.

```sh
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python bot.py
```

Для systemd разместите файлы в `/opt/halqmak`, установите зависимости в `/opt/halqmak/.venv` и создайте системного пользователя и группу `halqmak`. Храните `.env` с правами `0600` у root. Установите `halqmak.service` в `/etc/systemd/system` и запустите `systemctl enable --now halqmak`.
